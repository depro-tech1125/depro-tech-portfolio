DEPRO TECH SOLUTIONS — PORTFOLIO V2.1

Esta versión está preparada como catálogo comercial seguro.

CAMBIOS PRINCIPALES
- Se restauró el banner de empresas/clientes.
- Tu Techo Ideal y Membresía Venezuela aparecen como referencias de proyectos realizados.
- Se eliminó la arquitectura, orden de herramientas, procesos internos, datos de propiedades y cualquier detalle técnico del proyecto de Tu Techo Ideal.
- La demo ahora es conceptual y no representa a ningún cliente real.
- Se añadieron ejemplos genéricos de sistemas que Depro Tech puede desarrollar.
- Se añadió una nota explícita de confidencialidad.
- Se mantiene un diseño responsive para escritorio y móvil.

PUBLICACIÓN EN GITHUB PAGES
1. Reemplaza index.html, style.css y app.js del repositorio.
2. Copia la carpeta assets completa.
3. Conserva cualquier otro recurso que ya uses si lo necesitas.
4. No publiques credenciales, tokens, claves API, datos de clientes ni configuraciones internas.

NOTA
Los logotipos de los clientes incluidos en esta V2.1 se usan únicamente como referencias visuales en el catálogo. Los detalles técnicos de los proyectos no se publican.
